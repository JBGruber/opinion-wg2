# Annotation Task: Sort Opinion Measurement Tools into Categories

Your task is to annotate the results of a data extraction process focused on identifying 'tools' for opinion measurement.

**Definition of a Tool**: For this task, a 'tool' is defined as a measurement framework that incorporates software designed to detect, quantify, or classify concepts in text.

**Definition of an Opinion Measurement Tool (OMT)**: For this task, a “opinion measurement tool” is a computational system or method that automatically processes and analyzes textual data to infer evaluation, belief, or feeling of the author(s) towards a specific subject. There are general tools that can be used as OMTs, as well as OMTs that are specifically designed for measuring opinions.

The extracted data contains items that do not fit this definition, such as approaches, linguistic resources, and other non-tool entities. 

Your annotation should (a) classify the tools and approaches, (b) annotate whether the tool can be used for opinion measurement in general, (c) whether it is specifically designed for opinion measurement, (d) whether it is provided as reusable, installable software, and (e) extract the harmonized tool name.

## Categories

- **algorithm**: Specific algorithms or computational methods (e.g., SVM, Naive Bayes, LSTM)
- **model**: Pre-trained models or specific model architectures (e.g., BERT, GPT, domain-specific sentiment models)
- **linguistic_resource**: Lexicons, dictionaries, corpora, or knowledge bases (e.g., SentiWordNet, WordNet, opinion lexicons)
- **general_purpose_nlp**: Libraries designed for a range of NLP/text processing tasks (e.g., NLTK, spaCy, Stanford CoreNLP, quanteda)
- **single_purpose_nlp**: Dedicated software tools and libraries designed for one specific NLP task, including, but not limited to opinion measurement, stance detection, aspect based sentiment analysis, POS-tagging (e.g., OpinionFinder, Opinion Observer, TreeTagger)
- **general_library**: General-purpose programming libraries not specific to NLP (e.g., NumPy, Pandas, Matplotlib, ggplot)

- **approach**: High-level methodologies, frameworks, or conceptual approaches (e.g., "rule-based sentiment analysis", "aspect-based opinion measurement", "deep learning techniques")
- **programming_language**: General programming languages used for implementation (e.g., Python, Java, R)
- **ide**: Integrated Development Environments (e.g., PyCharm, Jupyter Notebook, RStudio)

- **data_collection**: Data sources and tools designed specifically for gathering data (e.g., web scrapers, Twitter API, survey platforms, data extraction tools)
- **infrastructure**: Platforms, cloud services, or computational infrastructure (e.g., AWS, Hadoop, Spark, distributed computing frameworks)

- **gui_tool**: Tools with graphical user interfaces that don't require programming (e.g., GATE, RapidMiner, text analysis software with visual interface)
- **commercial_api**: Commercial proprietary APIs and cloud services for NLP and sentiment analysis (e.g., Azure Text Analytics, Google Cloud Natural Language API, IBM Watson NLU, AWS Comprehend)
- **other_unclear**: Use this category only if none of the above categories match; do not make assumptions or force a classification
