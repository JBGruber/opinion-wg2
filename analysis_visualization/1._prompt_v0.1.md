# Annotation Task: Sort Opinion Mining Tools into Categories

Your task is to annotate the results of a data extraction process focused on identifying 'tools' for opinion mining.

**Definition of a Tool**: For this task, a 'tool' is defined as a measurement framework that incorporates software designed to detect, quantify, or classify concepts in text.

The extracted data contains items that do not fit this definition, such as approaches, linguistic resources, and other non-tool entities. Your annotation should classify the tools and approaches, extract a harmonized name, and distinguish between true tools and other resources.

## Categories

- **approach**: High-level methodologies, frameworks, or conceptual approaches (e.g., "rule-based sentiment analysis", "aspect-based opinion mining", "deep learning techniques")
- **programming_language**: General programming languages used for implementation (e.g., Python, Java, R)
- **ide**: Integrated Development Environments (e.g., PyCharm, Jupyter Notebook, RStudio)
- **general_library**: General-purpose programming libraries not specific to NLP (e.g., NumPy, Pandas, Matplotlib)
- **nlp_library**: Libraries specifically designed for NLP/text processing (e.g., NLTK, spaCy, Stanford CoreNLP)
- **algorithm**: Specific algorithms or computational methods (e.g., SVM, Naive Bayes, LSTM)
- **model**: Pre-trained models or specific model architectures (e.g., BERT, GPT, domain-specific sentiment models)
- **linguistic_resource**: Lexicons, dictionaries, corpora, or knowledge bases (e.g., SentiWordNet, WordNet, opinion lexicons)
- **data_collection**: Tools and resources specifically for gathering data (e.g., web scrapers, Twitter API clients, survey platforms, data extraction tools)
- **infrastructure**: Platforms, cloud services, or computational infrastructure (e.g., AWS, Hadoop, Spark, distributed computing frameworks)
- **gui_tool**: Tools with graphical user interfaces that don't require programming (e.g., GATE, RapidMiner, text analysis software with visual interface)
- **opinion_mining_tool**: Dedicated software tools specifically designed for measuring and extracting opinions from text (e.g., OpinionFinder, SentiStrength, Opinion Observer)
- **commercial_api**: Commercial proprietary APIs and cloud services for NLP and sentiment analysis (e.g., Azure Text Analytics, Google Cloud Natural Language API, IBM Watson NLU, AWS Comprehend)
- **other_unclear**: Use this category only if none of the above categories match; do not make assumptions or force a classification


## Output Format

Provide your annotation in the following JSON format:

```json
{
  "category": "approach|programming_language|ide|general_library|nlp_library|algorithm|model|linguistic_resource|data_collection|infrastructure|gui_tool|opinion_mining_tool|commercial_api|other_unclear",
  "tool_name_clean": "",
  "opinion_mining_tool": "yes|no|unclear",
  "note": "Brief explanation of the tool (1-2 sentences)"
}
```

## Guidelines

- **tool_name_clean**: Standardize the tool name (e.g., "scikit learn" → "scikit-learn", "NLTK library" → "NLTK")
- **opinion_mining_tool**: Mark "yes" only if the tool could be used to extract human opinions from text. General NLP tools or programming languages should be "no"
- **note**: Briefly describe what the tool does and why you assigned it to this category
